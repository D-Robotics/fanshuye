# 开发团队试点方案

## 任务树理解测试

使用固定的 30 项模拟任务，包括：

- 3 项 `NOW`、8 项 `NEXT`、其余 `LATER`。
- 至少 3 项无人负责、3 项人工阻塞、3 项依赖阻塞。
- 待处理、进行中、待评审和完成历史。

要求参与者依次完成：

1. 在 5 秒内指出最高行动等级任务。
2. 在 5 秒内指出无人负责和阻塞任务。
3. 通过 hover 找到指定任务的负责人文字。
4. 认领一个无人负责任务。
5. 遇到已被认领任务时选择加入协作而不是重复开工。

记录完成时间、错误次数、是否误解叶片编码以及悬浮窗打扰程度。若树显著慢于列表，则减少直接叶片数量或状态编码，不增加更多视觉通道。
