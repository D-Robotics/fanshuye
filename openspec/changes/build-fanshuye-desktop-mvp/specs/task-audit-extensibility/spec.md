## ADDED Requirements

### Requirement: 核心任务操作写入追加式审计
系统 SHALL 为任务创建、编辑、认领、转交、状态转换、阻塞变化、重要度变化、依赖变化和归档写入不可由普通成员篡改的追加式审计记录。

#### Scenario: 记录任务状态变化
- **WHEN** 任务状态转换成功提交
- **THEN** 系统在同一业务事务中记录操作者、来源、时间、任务版本及变更前后摘要

#### Scenario: 命令失败不产生成功审计
- **WHEN** 任务命令因权限、版本或状态机校验失败
- **THEN** 系统不得写入表示业务变化已经成功的审计事件

### Requirement: 任务动态时间线
系统 SHALL 向工作区成员提供按时间排序的任务动态时间线，并仅展示其有权限查看的审计内容。

#### Scenario: 查看任务历史
- **WHEN** 成员打开任务详情中的动态面板
- **THEN** 系统显示任务创建、负责人变化、状态变化、阻塞和依赖变化的时间与操作者文字

#### Scenario: 归档后保留动态
- **WHEN** 完成或取消任务从活跃树归档
- **THEN** 系统继续允许授权成员查询该任务的历史动态

### Requirement: 稳定且版本化的领域事件
系统 SHALL 为核心任务变化生成带稳定任务 ID、事件类型、模式版本、任务版本、发生时间、操作者类型、来源和载荷的领域事件。

#### Scenario: 生成人工操作事件
- **WHEN** 成员成功执行“认领并开始”
- **THEN** 系统生成可区分人工来源的 `TaskStarted` 或等价版本化领域事件

#### Scenario: 消费者面对未知事件版本
- **WHEN** 扩展消费者收到其不支持的事件模式版本
- **THEN** 消费者拒绝错误解释并记录可诊断信息，不得据此修改任务事实

### Requirement: 统一的任务命令边界
桌面客户端、系统任务以及未来集成和 Agent SHALL 通过相同的授权命令服务请求任务修改，不得绕过状态机、并发控制和审计直接修改任务表。

#### Scenario: 系统来源请求修改
- **WHEN** 内部系统组件请求变更任务状态
- **THEN** 命令服务执行与人工操作相同的权限策略、业务规则和审计要求

#### Scenario: 未来 Agent 建议被接受
- **WHEN** 后续版本中成员接受一条 Agent 状态建议
- **THEN** 接受动作通过普通任务命令产生正式状态变化，而不是由 Agent 直接写入任务数据

### Requirement: 通用外部引用
系统 SHALL 允许任务保存平台无关的外部引用标识、类型和链接，为后续关联仓库、Issue、分支或 PR 提供边界，但首版 SHALL NOT 自动读取外部平台活动。

#### Scenario: 保存普通外部链接
- **WHEN** 成员在任务详情中添加一个有效仓库或工单链接
- **THEN** 系统保存引用类型、显示名称和链接，并在详情中提供访问入口

#### Scenario: 外部服务不可用
- **WHEN** 外部引用目标不可访问
- **THEN** 系统的核心任务读取、状态更新和同步仍可正常工作

### Requirement: 依赖图投影边界
系统 SHALL 通过依赖领域事件允许后续构建 Neo4j 或其他图查询投影，同时 MUST 维持 PostgreSQL 中的任务和依赖关系为首版事实源。

#### Scenario: 依赖关系变化产生事件
- **WHEN** 有效依赖被新增或删除
- **THEN** 系统生成包含稳定任务 ID 和关系方向的版本化依赖事件

#### Scenario: 后期图投影不可用
- **WHEN** 后续部署的图查询投影停止服务或落后
- **THEN** 核心任务工作流继续依赖 PostgreSQL 事实运行，且不得从陈旧投影反向覆盖任务数据

### Requirement: 核心产品不依赖 Agent
首版系统 SHALL 在没有模型服务、向量数据库、进度推断或 Agent 调度器的情况下提供全部核心任务能力。

#### Scenario: 未配置任何 Agent
- **WHEN** 部署环境没有配置模型或 Agent 服务
- **THEN** 成员仍可创建、认领、更新、同步、阻塞、评审和完成任务

### Requirement: 敏感凭据不进入桌面缓存
系统 SHALL 将未来外部集成凭据与普通任务缓存分离，并 MUST NOT 在桌面 SQLite 任务缓存中保存服务端密钥或第三方访问令牌。

#### Scenario: 查看本地缓存内容
- **WHEN** 客户端保存可离线查看的任务快照
- **THEN** 缓存仅包含授权任务展示所需数据，不包含服务端密钥或第三方 OAuth 令牌
