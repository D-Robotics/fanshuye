## 4. 任务依赖 DAG

- [x] 4.1 在领域层定义 `DependencyCommandPort` 与 `DependencyQueryPort`，确保任务模块不依赖 PostgreSQL 或 Neo4j 特有查询。
- [x] 4.2 实现 PostgreSQL `BLOCKS` 依赖仓储，拒绝自依赖、重复边、跨工作区边和悬空任务引用。
- [x] 4.3 使用递归 CTE 实现前置、后续、可达性和有限影响子图查询，并设置超时与最大返回节点数。
- [x] 4.4 使用工作区图版本锁或等价事务策略实现新增边环路检查，保证直接环、间接环和并发成环均被拒绝。
- [x] 4.5 计算 `effectiveBlocked = manualBlocked OR hasIncompletePrerequisite`，同时向客户端分别返回人工阻塞和依赖阻塞原因。
- [x] 4.6 在存在未完成前置任务时拒绝开始任务，并返回直接未完成前置任务列表。
- [x] 4.7 在最后一个前置任务完成后解除依赖阻塞、重新计算行动等级并产生可同步事件，但不自动改变正式工作流状态。
- [x] 4.8 实现“前置任务阻塞更高行动等级后续任务时最多提升一档”的有限传播规则及解释。
- [x] 4.9 为依赖新增、删除和可执行性变化生成版本化领域事件，验证 PostgreSQL 在没有 Neo4j 时可完成全部 MVP 依赖能力。
