## Why

当前悬浮入口会在鼠标经过时自动展开，容易遮挡正在使用的窗口，也让用户缺少对弹窗时机的明确控制。收起态又只有一株很小的嫩芽，无法直接传达团队任务状态，没有充分发挥“叶子就是任务”的产品隐喻。

## What Changes

- 移除鼠标悬停自动展开与移出自动收起，悬浮窗只在用户点击后展开或收起。
- 将收起态重绘为一株有心形阔叶、分层叶簇、枝干和番薯根块的品牌化番薯植株，参考用户提供的形象但使用原创 SVG/CSS 实现。
- 在常驻悬浮植株上直接显示最高行动等级的任务叶片，使用叶片大小、轮廓、状态符号和异常徽标表达任务信息。
- 允许用户点击具体任务叶片直接展开并选中该任务；点击植株空白区域则展开任务树总览。
- 对超出常驻叶片容量的任务显示数量徽标，并保留完整任务树与列表作为展开后的入口。
- 保持叶片不显示负责人头像，责任人仍只在展开后的卡片和详情中以文字显示。
- 调整原生收起窗口尺寸、命中区域和透明窗口布局，使新植株在 Windows 桌面上清晰可点且不过度遮挡。

## Capabilities

### New Capabilities

- `clickable-task-plant-overlay`: 点击式悬浮交互、品牌化番薯植株、常驻任务叶片、任务直达和溢出摘要。

### Modified Capabilities

无。当前主规格目录尚未建立；本变更以独立能力规格补充现有 MVP 变更。

## Impact

- 影响桌面端 overlay 状态机、React 悬浮入口、共享任务叶片视觉组件和窗口交互测试。
- 影响 Tauri 原生 overlay 窗口的收起尺寸、定位及鼠标命中区域。
- 不改变任务 API、同步协议、数据库模式、登录流程或任务权限。
- 不引入图片运行时依赖；参考形象将转换为代码内 SVG/CSS 视觉语言。
